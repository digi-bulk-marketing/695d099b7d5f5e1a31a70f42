# Undercar

Undercar by Undercar.

## Installation

### Windows
1. Download the latest **`.exe`** installer from the [Releases page](https://github.com/digi-bulk-marketing/695d099b7d5f5e1a31a70f42/releases/latest).
2. Run the installer and follow the prompts.
3. Launch **Undercar** from the Start menu.

## Updates

Download the newest installer from the [Releases page](https://github.com/digi-bulk-marketing/695d099b7d5f5e1a31a70f42/releases/latest) and reinstall.
